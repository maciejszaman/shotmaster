# Shotmaster v1.1.0
###  very simple app for trimming / cutting videos
- one button clip compression to 10MB
- full set of keyboard shortcuts to speed up the process
- linux and windows compatible
- usable in the command line

### Installation
run the install script next to the ```Shotmaster-1.1.0-linux-x86_64.AppImage```

### CLI
usable in terminal by a ```shotmaster -s <source> -o <output> -t <start percent> -c <target size in MB>```
<br>
Example:
```shotmaster -s ~/Videos/clip.mp4 -o ~/Videos/out.mp4 -t 90 -c 8```
